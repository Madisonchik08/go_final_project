# Планировщик задач

Веб-приложение для управления задачами с возможностью повторения. Позволяет создавать, редактировать, удалять и отмечать выполненные задачи. Поддерживает повторяющиеся задачи с различными форматами повторения (ежедневно, еженедельно, ежемесячно, ежегодно).

## Выполненные задания со звёздочкой

1. Реализована аутентификация с использованием JWT-токенов
   - Поддержка входа по паролю через переменную окружения TODO_PASSWORD
   - Генерация JWT-токена с хэшем пароля
   - Проверка аутентификации для защищённых API-эндпоинтов

2. Создан Docker-образ для деплоя приложения
   - Multi-stage сборка для уменьшения размера образа
   - Поддержка переменных окружения
   - Запуск от непривилегированного пользователя

## Запуск кода локально

### Переменные окружения

Поддерживаемые переменные окружения:
- `TODO_PORT` - порт веб-сервера (по умолчанию 7540)
- `TODO_DBFILE` - путь к файлу базы данных SQLite (по умолчанию scheduler.db)
- `TODO_PASSWORD` - пароль для аутентификации
- `TODO_JWT_SECRET` - секрет для подписи JWT-токенов (по умолчанию "my_secret_key")

### Пример запуска

```bash
TODO_PORT=7540 TODO_DBFILE=scheduler.db TODO_PASSWORD=12345 go run main.go
```

После запуска приложение будет доступно по адресу: http://localhost:7540

## Запуск тестов

1. Установите переменную `Token` в файле `tests/settings.go` в значение токена, полученного после успешного входа через `/api/signin`
2. При необходимости измените значения `Port` и `DBFile`
3. Запустите тесты:

```bash
TODO_PASSWORD=12345 go test ./tests
```

## Сборка и запуск через Docker

### Сборка образа

```bash
docker build -t go-final-project .
```

### Запуск контейнера

```bash
docker run -p 7540:7540 \
  -v ${PWD}/scheduler.db:/app/scheduler.db \
  -e TODO_DBFILE=/app/scheduler.db \
  -e TODO_PORT=7540 \
  -e TODO_PASSWORD=12345 \
  go-final-project
```

После запуска контейнера приложение будет доступно по адресу: http://localhost:7540

База данных будет сохраняться на хосте в файле scheduler.db и будет доступна между перезапусками контейнера.
